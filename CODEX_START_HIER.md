# De StalKas — overdracht naar Codex

Dit is een complete, kant-en-klare PWA-site (HTML, manifest, service worker, iconen). **Nog niet automatisch gepubliceerd.**

**Bestaande repository:** https://github.com/riannesplinter/De-stalkas

**Gewenste website (na GitHub Pages-publicatie):** https://riannesplinter.github.io/De-stalkas/

Opdracht voor Codex: gebruik de bestanden in dit pakket om de bestaande repo te vullen, controleer de werking, activeer waar toegestaan GitHub Pages op `main` (root), en verifieer de openbare URL. Vraag alleen toestemming als de GitHub-koppeling dit echt vereist. Lees `AGENTS.md` voor functies en randvoorwaarden.

Gebruik het pakket niet als grond om te claimen dat er centrale synchronisatie is: alle gegevens worden lokaal op het apparaat opgeslagen.
